## [Unreleased]

### Added

- Phase 1: Project structure, Git configuration, and documentation skeleton
- Phase 2: Django project with PostgreSQL, Redis, and Celery
- Phase 3: Custom User model, JWT authentication, and user profiles
- Phase 4: Security infrastructure (audit logs, prompt guard, rate limiting)
- Phase 5: Database models (10 Django apps, 22 models)
- Phase 6: REST API endpoints (~60 endpoints)
- Phase 7: Multi-agent framework (base, orchestrator, tools, first agent)
- Phase 8: LLM integration (prompts, JSON parser, ResumeAgentLLM)
- Phase 9: JobAgent for job parsing and matching
- Phase 10: SkillGapAgent for prioritized gap analysis
- Phase 11: InterviewAgent for mock interviews
- Phase 12: RAG with ownership-enforced retrieval
- Phase 13: Verification layer with deterministic checks
- Phase 14: Human-in-the-loop approval workflow
- Phase 15: Observability (traces, metrics, events)
- Phase 16: Rate limiting and cost control
- Phase 17: Agent framework documentation
